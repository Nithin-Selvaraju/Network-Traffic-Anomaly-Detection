Attack Decomposition

Attack Family Profiles & Triage Criteria

  • Denial of Service (DoS): Attacks designed to saturate bandwidth or exhaust resources (e.g. neptune, smurf, pod, teardrop, back). Detected via high connection rates and SYN errors.
  • Probing (Probe): Reconnaissance scans to map network ports and discover vulnerabilities (e.g. ipsweep, portsweep, nmap, satan, mscan). Detected via service variance metrics.
  • Remote to Local (R2L): Unauthorized remote access attempts (e.g. guess_passwd, ftp_write, imap, warezclient). Characterized by failed login counters and root shell attempts.
  • User to Root (U2R): Privilege escalation exploits by local users (e.g. buffer_overflow, loadmodule, rootkit, perl). Detected via content payload execution features.

Network Feature Dictionary & Security Implications

flag

Connection error/status flag (e.g., SF for normal, S0 for SYN flood, REJ for rejected probe)

same_srv_rate

% of connections to the same service in the 2s time window

dst_host_srv_count

Number of connections to same service on destination host (last 100 connections)

dst_host_same_srv_rate

% of connections to same service on destination host

logged_in

1 if successfully logged in; 0 otherwise (exploits and scans typically fail login)

diff_srv_rate

% of connections to different services in the 2s time window

dst_host_diff_srv_rate

% of connections to different services on destination host

count

Number of connections to the same host in last 2 seconds

dst_host_count

Count of connections to destination host over the last 100 connections

src_bytes

Number of payload data bytes sent from source to destination

dst_bytes

Number of payload data bytes returned from destination to source

dst_host_same_src_port_rate

% of connections from the same source port to destination host

srv_count

Number of connections to the same service in last 2 seconds

dst_host_serror_rate

% of connections to destination host with SYN errors

serror_rate

% of connections with SYN errors in the last 2 seconds
